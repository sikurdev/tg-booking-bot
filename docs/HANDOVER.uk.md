## Що ви отримуєте

1. Telegram-бот для онлайн-запису клієнтів (українською; за потреби російською).
2. Миттєві сповіщення вам про кожен новий запис і кожне скасування.
3. Команда `/admin` — записи на сьогодні/завтра, скасування запису (клієнт отримає повідомлення), блокування дня або проміжку часу.
4. Файл налаштувань бізнесу (YAML) і базу записів SQLite на сервері.

## Як клієнти користуються

- `/start` — вітання, адреса, години, кнопка «Записатися».
- Обирають послугу → дату (лише робочі дні) → вільний час → ім’я → телефон → підтвердження.
- `/my` — свої майбутні записи; можна скасувати.

## Як змінити години роботи та послуги

Попросіть виконавця (або зробіть самі, якщо маєте доступ до сервера) відредагувати файл конфігурації, наприклад `config/your_business.yaml`:

```yaml
working_hours:
  0: { open: "10:00", close: "19:00" }  # 0=понеділок … 6=неділя
  # немає дня = вихідний

days_off:
  - "2026-12-25"   # додаткові вихідні

services:
  - id: haircut
    name: "Стрижка"
    duration_minutes: 45
    price: "Ціна за запитом"   # або число, напр. 450
```

Після збереження файлу **перезапустіть бота** (виконавець зробить `systemctl restart …` або еквівалент).
Код бота змінювати не потрібно — лише цей файл.

## Адмін-команди власника

| Дія | Як |
| --- | --- |
| Панель | `/admin` (працює лише з вашого акаунта) |
| Сьогодні / завтра | кнопки в панелі |
| Скасувати запис | кнопка біля запису — клієнт отримає сповіщення |
| Заблокувати день | «Заблокувати час» → надіслати `YYYY-MM-DD` |
| Заблокувати інтервал | надіслати `YYYY-MM-DD HH:MM — YYYY-MM-DD HH:MM` |

## Важливо

- Не публікуйте токен бота й не пересилайте файл `.env`.
- Якщо змінили телефон бізнесу або адресу — оновіть YAML і перезапустіть.
- Резервна копія: файл бази `data/bookings.db` + YAML.
